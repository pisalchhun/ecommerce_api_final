# Ecommerce API

This is an Ecommerce API built using Flask. It provides full backend functionality for an online shopping system, including product management, user authentication, order processing, cart management, and admin control panel features.

The API is structured into two main sections:
- Admin Panel APIs (for system management)
- Front Panel APIs (for user experience)

---

## Features

### Authentication 
- User Registration
- User Login
- Logout
- JWT Token Authentication
- Token validation

---

### Admin Panel

#### + Product Management
- Get all products
- Create product
- Update product
- Delete product

#### + Category Management
- Manage product categories

#### + User Management
- View users
- Manage user data

#### + Order Management
- View all orders
- Update order status
- Delete order

---

### Front Panel (Customer Side)

#### + Cart
- Add to cart
- View cart
- Update cart items
- Remove items

#### + Checkout
- Create order
- View orders
- Update order
- Delete order

#### + Order Tracking
- Track order status
- View tracking history

---
